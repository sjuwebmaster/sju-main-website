# SDG Assets

## Official UN SDG Images

Download the official logos from:
https://www.un.org/sustainabledevelopment/wp-content/uploads/2025/07/E-SDG-logos-SDG-wheel_No-UN-Emblem.zip

After downloading and extracting, place files in `/sdg/assets/img/`:

### Expected file names (rename after extracting):
- `sdg-wheel.png`         — Full SDG wheel (no UN emblem)
- `sdg-01.png`            — Goal 1: No Poverty
- `sdg-02.png`            — Goal 2: Zero Hunger
- `sdg-03.png`            — Goal 3: Good Health
- `sdg-04.png`            — Goal 4: Quality Education
- `sdg-05.png`            — Goal 5: Gender Equality
- `sdg-06.png`            — Goal 6: Clean Water
- `sdg-07.png`            — Goal 7: Clean Energy
- `sdg-08.png`            — Goal 8: Decent Work
- `sdg-09.png`            — Goal 9: Innovation
- `sdg-10.png`            — Goal 10: Reduced Inequalities
- `sdg-11.png`            — Goal 11: Sustainable Cities
- `sdg-12.png`            — Goal 12: Responsible Consumption
- `sdg-13.png`            — Goal 13: Climate Action
- `sdg-14.png`            — Goal 14: Life Below Water
- `sdg-15.png`            — Goal 15: Life on Land
- `sdg-16.png`            — Goal 16: Peace & Justice
- `sdg-17.png`            — Goal 17: Partnerships

The pages use these paths as `assets/img/sdg-01.png` etc.
If an image is missing, the pages fall back to the coloured tile with number.
